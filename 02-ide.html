IDE 설치와 첫 업로드

코드를 보드에 올리려면 프로그램 하나가 필요합니다. 설치하고, 보드를 연결하고, 내장 LED를 깜빡이게 만드는 데까지 15분이면 충분합니다.

이 강의를 마치면

  • Arduino IDE를 설치하고 실행할 수 있다
  • 보드 종류와 포트를 올바르게 선택할 수 있다
  • 예제 스케치를 업로드해 내장 LED를 깜빡이게 할 수 있다
  • 업로드 오류가 났을 때 스스로 원인을 찾아볼 수 있다

다운로드

공식 사이트 arduino.cc/en/software 에 접속합니다. 여러 버전이 보이는데, Arduino IDE 2.x 를 받으면 됩니다. 무료입니다.

내 컴퓨터받을 파일
윈도우Windows Win 10 and newer, 64 bits — 설치 파일(.exe)
맥 (M1/M2/M3/M4)macOS Apple Silicon — .dmg
맥 (인텔)macOS Intel — .dmg
기부 요청 화면이 뜨면

다운로드 버튼을 누르면 후원을 부탁하는 페이지가 나옵니다. JUST DOWNLOAD를 누르면 결제 없이 바로 받을 수 있습니다.

내 맥이 어느 쪽인지 모르겠다면

왼쪽 위 사과 메뉴 → 이 Mac에 관하여를 열어 칩 항목을 봅니다. “Apple M…”이면 Apple Silicon, “Intel Core…”면 Intel입니다.

설치하기

윈도우

  1. 설치 파일 실행

    받은 arduino-ide_…_Windows_64bit.exe를 더블클릭합니다.

  2. “Windows의 PC 보호” 경고가 뜨면

    추가 정보 → 실행을 누릅니다. 공식 배포 파일이라 안전합니다.

  3. 라이선스 동의 후 설치

    경로는 기본값 그대로 두고 Install을 누릅니다.

  4. 드라이버 설치 창을 허용

    설치 도중 “이 장치 소프트웨어를 설치하시겠습니까?”가 여러 번 뜹니다. 모두 설치를 눌러야 보드가 인식됩니다.

맥

  1. dmg 열기

    받은 .dmg 파일을 더블클릭합니다.

  2. 응용 프로그램으로 드래그

    Arduino IDE 아이콘을 옆의 Applications 폴더로 끌어다 놓습니다.

  3. 첫 실행 시 경고가 뜨면

    “확인되지 않은 개발자” 경고가 나오면, 아이콘을 우클릭 → 열기로 실행하거나 시스템 설정 → 개인정보 보호 및 보안에서 확인 없이 열기를 누릅니다.

호환 보드(클론)를 쓴다면 — CH340 드라이버

정품이 아닌 저가 우노 보드는 USB 칩이 CH340인 경우가 많습니다. 이 경우 보드를 꽂아도 포트 목록에 아무것도 안 뜹니다. CH340 드라이버를 따로 설치한 뒤 컴퓨터를 재시작하세요. 맥에서는 /dev/cu.wchusbserial… 같은 이름으로 나타납니다.

IDE 화면 익히기

처음 실행하면 아래와 같은 창이 열립니다. 지금은 버튼 두 개와 드롭다운 하나만 알면 됩니다.

버튼단축키하는 일
✓ 검증Ctrl/⌘ + R코드에 문법 오류가 없는지만 확인합니다. 보드가 없어도 됩니다.
→ 업로드Ctrl/⌘ + U검증한 뒤 보드에 실제로 올립니다. 보드가 연결되어 있어야 합니다.
🔍 시리얼 모니터Ctrl/⌘ + Shift + M보드가 보낸 메시지를 화면에 띄웁니다.

한국어로 바꾸려면 File(파일) → Preferences(환경설정) → Language에서 한국어를 선택하고 IDE를 다시 켜면 됩니다.

보드 연결과 포트 설정

  1. USB 케이블로 보드를 연결합니다

    보드의 ON LED에 초록 불이 들어오면 전원이 들어온 것입니다. 불이 안 들어오면 케이블이 충전 전용일 가능성이 높습니다.

  2. 보드 종류를 고릅니다

    도구 → 보드 → Arduino AVR Boards → Arduino Uno

  3. 포트를 고릅니다

    도구 → 포트에서 나타난 항목을 선택합니다.

    • 윈도우: COM3, COM5 같은 이름 (COM1은 보통 아님)
    • 맥: /dev/cu.usbmodem… 또는 /dev/cu.wchusbserial…
  4. 툴바 드롭다운을 확인합니다

    화면 위 드롭다운에 Arduino Uno와 포트 이름이 함께 보이면 준비 완료입니다.

어느 포트인지 모르겠다면

USB를 뽑은 상태에서 포트 목록을 확인하고, 다시 꽂은 뒤 목록을 봅니다. 새로 생긴 것이 아두이노입니다.

첫 업로드 — Blink

IDE에는 예제가 기본으로 들어 있습니다. 파일 → 예제 → 01.Basics → Blink 를 엽니다. 아래와 같은 코드가 열립니다. (주석은 우리말로 바꿔 두었습니다.)

Blink.ino
void setup() {
  // LED_BUILTIN 은 보드에 내장된 LED, 즉 13번 핀을 뜻합니다.
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);  // 켬
  delay(1000);                      // 1초 대기
  digitalWrite(LED_BUILTIN, LOW);   // 끔
  delay(1000);                      // 1초 대기
}

→ 업로드 버튼을 누릅니다. 아래 출력 창에 흰 글씨가 지나가고, 보드의 TX·RX LED가 빠르게 깜빡인 뒤 멈춥니다. 그러고 나면 보드의 L LED가 1초 간격으로 깜빡입니다.

성공 신호

출력 창에 스케치가 프로그램 저장 공간 …바이트를 사용합니다(영문: Sketch uses … bytes)라는 문장이 보이면 업로드 성공입니다.

바꿔보기

delay(1000) 두 곳을 모두 delay(100)으로 바꾸고 다시 업로드해 보세요. 훨씬 빠르게 깜빡입니다. 코드를 바꿨으면 반드시 다시 업로드해야 반영됩니다. 저장만 해서는 바뀌지 않습니다.

도전 — 모스 부호로 SOS

짧게 3번(0.2초), 길게 3번(0.6초), 짧게 3번 깜빡이게 만들어 보세요. 각 깜빡임 사이에는 0.2초 쉬고, 한 세트가 끝나면 2초 쉽니다.

힌트 보기

digitalWrite(HIGH) → delay(켤 시간) → digitalWrite(LOW) → delay(0.2초) 를 9번 쓰면 됩니다. 반복되는 부분이 지저분해 보인다면 정상입니다. 4강에서 이걸 함수로 깔끔하게 정리하는 법을 배웁니다.

업로드가 안 될 때

수업에서 나오는 오류의 90%는 아래 네 가지 중 하나입니다. 위에서부터 순서대로 확인하세요.

증상 / 메시지원인과 해결
포트 목록이 비어 있음 ① 케이블이 충전 전용 → 데이터 케이블로 교체 ② 클론 보드인데 CH340 드라이버 미설치 ③ USB 허브 대신 노트북에 직접 연결
Serial port not selected
포트가 선택되지 않았습니다		 도구 → 포트에서 포트를 고르지 않았습니다. 위 보드 연결 3번을 다시 하세요.
programmer is not responding
stk500_recv(): programmer is not responding		 보드가 응답하지 않습니다. ① 0번·1번 핀에 꽂힌 선을 모두 빼고 다시 시도 ② 다른 포트를 선택 ③ USB를 뽑았다 꽂기 ④ 보드의 RESET 버튼을 누른 직후 업로드
expected ';' before … 문법 오류입니다. 오류 줄 바로 위 줄에 세미콜론이 빠졌을 가능성이 큽니다. IDE가 빨간 줄로 위치를 알려 줍니다.
'xxx' was not declared in this scope 변수나 함수 이름의 철자·대소문자가 틀렸습니다. digitalwrite ✗ → digitalWrite ✓
Access is denied / Port busy 시리얼 모니터나 다른 프로그램이 포트를 잡고 있습니다. 시리얼 모니터 창을 닫고 다시 업로드하세요.
그래도 안 되면

USB를 뽑고, IDE를 완전히 종료했다가 다시 켠 뒤, USB를 꽂고 보드 → 포트를 다시 선택해 보세요. 이 순서로 대부분 해결됩니다.

시리얼 모니터

보드에는 화면이 없습니다. 그래서 지금 값이 얼마인지 확인하려면 보드가 컴퓨터로 글자를 보내게 해야 합니다. 그게 시리얼 통신이고, 그 글자를 보는 창이 시리얼 모니터입니다. 앞으로 문제를 찾을 때 가장 많이 쓰게 됩니다.

SerialHello.ino
void setup() {
  Serial.begin(9600);        // 통신 속도를 9600으로 시작
  Serial.println("보드 준비 완료!");
}

int count = 0;

void loop() {
  count = count + 1;
  Serial.print("경과 시간(초): ");
  Serial.println(count);
  delay(1000);
}

업로드한 뒤 도구 → 시리얼 모니터를 엽니다. 창 오른쪽 아래의 속도가 9600 baud인지 확인하세요. 코드의 숫자와 모니터의 숫자가 다르면 글자가 깨져서 알아볼 수 없는 기호가 나옵니다.

print 와 println 의 차이

Serial.print()는 이어서 쓰고, Serial.println()은 쓰고 나서 줄을 바꿉니다. 위 코드처럼 섞어 쓰면 경과 시간(초): 1 이 한 줄로 예쁘게 나옵니다.
