프로젝트와 연계하기
자기장 센서 읽기

버튼은 켜짐/꺼짐 두 가지만 알려 줍니다. 센서는 “얼마나”를 알려 줍니다. 자기장 센서를 아날로그 입력으로 읽어 X·Y·Z 세 축의 값을 시리얼로 내보내고, 그 값으로 무언가를 판단하는 데까지 가 봅니다.

이 강의를 마치면

  • analogRead()로 0~1023 값을 읽고 전압으로 바꿀 수 있다
  • 센서 세 축을 동시에 읽어 시리얼로 보기 좋게 출력할 수 있다
  • 시리얼 플로터로 값의 변화를 그래프로 확인할 수 있다
  • 기준값 보정과 노이즈 필터가 왜 필요한지 안다
  • 센서 값으로 LED·부저를 제어해 하나의 장치를 완성할 수 있다

왜 자기장 센서인가

자기장은 눈에 보이지 않지만 항상 우리 주위에 있는 물리량입니다. 지구 자체가 커다란 자석이라 어디서나 지구 자기장이 잡히고, 자석·전선·모터 근처에서는 값이 크게 흔들립니다. 센서 하나로 이런 것들을 만들 수 있습니다.

  • 디지털 나침반 — X·Y 값으로 방향을 계산
  • 금속·자석 탐지기 — 값이 갑자기 변하면 감지
  • 문·창문 열림 감지 — 문틀에 자석을 붙여 두고 멀어지면 알림
  • 회전수 측정 — 바퀴에 자석을 붙여 지나갈 때마다 세기
  • 비접촉 스위치 — 손대지 않고 자석만 가까이 대서 켜기

센서와 연결

이 강의가 대상으로 하는 센서

X·Y·Z 각각의 아날로그 출력 핀이 따로 나와 있는 3축 자기장 센서 모듈입니다. 핀 이름이 VCC · GND · X · Y · Z (또는 OUTX/OUTY/OUTZ)로 되어 있으면 이 방식입니다. 홀 센서(SS49E, A1302 등)를 세 개 써서 축마다 하나씩 붙여도 똑같이 동작합니다.

내 모듈에 SDA·SCL 핀이 있다면

그건 I2C 방식(디지털) 센서입니다. HMC5883L, QMC5883L, MLX90393 등이 여기에 해당합니다. 이 경우 analogRead()로는 읽을 수 없고 전용 라이브러리가 필요합니다. 아래 I2C 모듈이라면 절을 참고하세요. 배선과 코드는 다르지만, 읽은 뒤의 처리는 이 강의 내용이 그대로 적용됩니다.

전압을 꼭 확인하세요

모듈이 3.3V 전용인데 5V를 물리면 센서가 손상됩니다. 기판에 3V3, 3.3V ONLY 같은 표시가 있는지 먼저 보세요. 판단이 안 서면 3.3V에 연결하는 쪽이 안전합니다 — 값이 작게 나올 뿐 고장은 나지 않습니다.

아날로그 입력 이해하기

버튼은 digitalRead()로 0 또는 1만 읽었습니다. 센서는 0V와 5V 사이의 어떤 전압을 내보내므로, 그 중간값까지 읽어야 합니다. 이때 쓰는 것이 analogRead()입니다.

들어오는 전압analogRead()의미
0 V0최소
1.25 V256
2.5 V512자기장이 없을 때 대개 이 근처
3.75 V768
5 V1023최대

아두이노 우노의 아날로그-디지털 변환기(ADC)는 10비트입니다. 210 = 1024, 그래서 0 ~ 1023의 1024단계로 나눠 읽습니다. 한 칸의 크기는 5V ÷ 1024 ≈ 0.0049V, 약 4.9mV입니다.

값 → 전압 변환
전압 = 읽은값 × 5.0 ÷ 1023.0

  예)  512 × 5.0 ÷ 1023.0 = 2.50 V
       800 × 5.0 ÷ 1023.0 = 3.91 V
자기장 센서의 중요한 성질

자기장은 방향이 있어서 (+)와 (−)가 모두 나올 수 있습니다. 그런데 센서는 음의 전압을 낼 수 없죠. 그래서 자기장이 0일 때 전원의 절반(약 2.5V)을 내보내고, 거기서 올라가면 한쪽 방향, 내려가면 반대 방향을 뜻하도록 만들어져 있습니다. 즉 512가 기준선이고, 우리는 512에서 얼마나 벗어났는지를 봐야 합니다.

1단계 · 세 축 읽어서 출력하기

MagRead.ino
const int PIN_X = A0;
const int PIN_Y = A1;
const int PIN_Z = A2;

void setup() {
  Serial.begin(9600);
  Serial.println("자기장 센서 시작");
}

void loop() {
  int x = analogRead(PIN_X);   // 0 ~ 1023
  int y = analogRead(PIN_Y);
  int z = analogRead(PIN_Z);

  Serial.print("X: ");
  Serial.print(x);
  Serial.print("\tY: ");     // \t = 탭(간격)
  Serial.print(y);
  Serial.print("\tZ: ");
  Serial.println(z);         // 마지막은 println 으로 줄바꿈

  delay(200);
}

업로드하고 도구 → 시리얼 모니터를 엽니다. 속도는 9600 baud입니다.

문법뜻
A0아날로그 0번 핀. const int PIN_X = A0; 처럼 이름을 붙여 두면 나중에 핀을 바꾸기 쉽습니다.
analogRead(핀)그 핀의 전압을 0~1023 숫자로 읽습니다. 한 번 읽는 데 약 100마이크로초가 걸립니다.
"\t"탭 문자. 값들을 세로로 가지런히 맞춰 줍니다.

2단계 · 시리얼 플로터로 보기

숫자가 빠르게 흘러가면 변화를 읽기 어렵습니다. Arduino IDE에는 시리얼 플로터가 들어 있어서, 숫자를 그래프로 그려 줍니다. 도구 → 시리얼 플로터로 열 수 있습니다.

다만 플로터가 알아듣는 출력 형식이 정해져 있습니다. 이름:값 을 쉼표로 이어 붙이고 줄바꿈으로 끝내야 합니다.

MagPlot.ino
const int PIN_X = A0;
const int PIN_Y = A1;
const int PIN_Z = A2;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int x = analogRead(PIN_X);
  int y = analogRead(PIN_Y);
  int z = analogRead(PIN_Z);

  // 시리얼 플로터 형식:  X:511,Y:508,Z:517
  Serial.print("X:");
  Serial.print(x);
  Serial.print(",Y:");
  Serial.print(y);
  Serial.print(",Z:");
  Serial.println(z);

  delay(50);      // 초당 20번 — 그래프가 부드럽게 그려집니다
}
플로터를 쓸 때 주의
  • 시리얼 모니터와 플로터를 동시에 열 수 없습니다. 하나를 닫고 다른 하나를 여세요.
  • Serial.println("시작합니다") 같은 글자만 있는 출력이 섞이면 그래프가 깨집니다. 플로터를 쓸 때는 숫자만 보내세요.
  • 플로터의 속도(baud)도 9600으로 맞춰야 합니다.

플로터에서 보이는 모습

아래는 시리얼 플로터를 흉내 낸 것입니다. 슬라이더로 자석을 가까이 가져가면 세 축이 어떻게 반응하는지 보세요.

X Y Z 점선 = 기준선 512

3단계 · 기준값 보정

앞에서 “자기장이 없으면 512쯤”이라고 했지만, 실제로는 센서마다 다릅니다. 어떤 축은 498, 어떤 축은 527에서 시작합니다. 제조 오차이고 정상입니다. 그래서 켜질 때 지금 값을 기준으로 기억해 두고, 앞으로는 그 차이만 보는 것이 정확합니다.

MagCalibrate.ino
const int PIN_X = A0;
const int PIN_Y = A1;
const int PIN_Z = A2;

// 각 축의 기준값 (setup에서 측정)
int baseX = 0, baseY = 0, baseZ = 0;

// 여러 번 읽어 평균을 내는 함수 — 노이즈를 줄여 줍니다
int readAverage(int pin, int times) {
  long sum = 0;                       // 큰 수를 담아야 하므로 long
  for (int i = 0; i < times; i++) {
    sum += analogRead(pin);
    delay(2);
  }
  return sum / times;
}

void setup() {
  Serial.begin(9600);

  Serial.println("보정 중… 센서 주변에서 자석을 치워 주세요");
  delay(2000);

  baseX = readAverage(PIN_X, 50);     // 50번 읽어 평균
  baseY = readAverage(PIN_Y, 50);
  baseZ = readAverage(PIN_Z, 50);

  Serial.print("기준값  X=");  Serial.print(baseX);
  Serial.print("  Y=");        Serial.print(baseY);
  Serial.print("  Z=");        Serial.println(baseZ);
  Serial.println("보정 완료");
}

void loop() {
  // 기준값을 뺀 '변화량'. 음수가 나올 수 있습니다.
  int x = analogRead(PIN_X) - baseX;
  int y = analogRead(PIN_Y) - baseY;
  int z = analogRead(PIN_Z) - baseZ;

  Serial.print("X:");   Serial.print(x);
  Serial.print(",Y:");  Serial.print(y);
  Serial.print(",Z:");  Serial.println(z);

  delay(50);
}
보정하고 나면 무엇이 좋아지나

이제 아무것도 없을 때 세 값이 모두 0 근처가 됩니다. 자석을 대면 그만큼 0에서 벗어나죠. 512인지 498인지 신경 쓸 필요 없이 “변했다 / 안 변했다”를 바로 판단할 수 있습니다. 시리얼 플로터로 보면 세 선이 모두 0 근처에 모여 훨씬 읽기 좋습니다.

보정 중에는 자석을 치우세요

보정하는 2초 동안 자석이 근처에 있으면, 그 상태가 “기준”이 되어 버립니다. 그러면 자석을 치웠을 때 오히려 값이 크게 나옵니다. 시리얼 모니터의 안내 문구가 이걸 위해 있는 것입니다.

4단계 · 세기 계산하고 판단하기

축이 세 개라 값도 세 개입니다. 하지만 “자석이 가까이 있나?”를 판단할 때는 방향과 상관없이 얼마나 센지 하나의 숫자로 알면 편합니다. 세 축을 하나로 합치는 방법은 피타고라스 정리를 3차원으로 확장한 것입니다.

세기(크기) 구하기
세기 = √(x² + y² + z²)

  예)  x=30, y=-40, z=0  일 때
       √(900 + 1600 + 0) = √2500 = 50
MagDetect.ino
const int PIN_X = A0;
const int PIN_Y = A1;
const int PIN_Z = A2;
const int LED    = 13;   // 출력
const int BUZZER = 7;    // 출력

const int THRESHOLD = 40;   // 이 값을 넘으면 '감지'로 판단

int baseX = 0, baseY = 0, baseZ = 0;

int readAverage(int pin, int times) {
  long sum = 0;
  for (int i = 0; i < times; i++) { sum += analogRead(pin); delay(2); }
  return sum / times;
}

void setup() {
  Serial.begin(9600);
  pinMode(LED, OUTPUT);
  pinMode(BUZZER, OUTPUT);

  Serial.println("보정 중… 자석을 치워 주세요");
  delay(2000);
  baseX = readAverage(PIN_X, 50);
  baseY = readAverage(PIN_Y, 50);
  baseZ = readAverage(PIN_Z, 50);
  Serial.println("보정 완료");
}

void loop() {
  // ① 입력
  int x = analogRead(PIN_X) - baseX;
  int y = analogRead(PIN_Y) - baseY;
  int z = analogRead(PIN_Z) - baseZ;

  // ② 연산 — 세 축을 하나의 세기로
  float strength = sqrt((long)x * x + (long)y * y + (long)z * z);

  Serial.print("X:");   Serial.print(x);
  Serial.print(",Y:");  Serial.print(y);
  Serial.print(",Z:");  Serial.print(z);
  Serial.print(",S:");  Serial.println(strength);

  // ③ 출력 — 임계값을 넘으면 알린다
  if (strength > THRESHOLD) {
    digitalWrite(LED, HIGH);
    tone(BUZZER, 1200, 60);      // 기다리지 않는 짧은 삑
  } else {
    digitalWrite(LED, LOW);
  }

  delay(50);
}
문법뜻
float소수점이 있는 수를 담는 그릇. sqrt()의 결과는 소수가 될 수 있습니다.
sqrt(값)제곱근을 구합니다. 아두이노에 기본으로 들어 있습니다.
(long)x * x중요. int는 최대 32767까지만 담깁니다. x가 200이면 x*x는 40000이라 넘쳐서 이상한 값이 됩니다. (long)을 붙여 큰 그릇으로 바꿔 계산합니다.
THRESHOLD“이 정도면 감지된 것”이라고 정하는 기준선. 센서와 자석에 따라 직접 조정해야 합니다.
임계값은 어떻게 정하나

정답이 없습니다. 측정해서 정하는 것입니다. 먼저 시리얼 플로터로 S 값을 보면서 ① 자석이 없을 때 얼마까지 흔들리는지, ② 원하는 거리에서 얼마가 나오는지를 확인하세요. 그 사이의 값을 고르면 됩니다. 노이즈가 15까지 튄다면 40 정도가 안전합니다.

참고 · I2C 모듈이라면

센서에 SDA·SCL 핀이 있다면 아날로그가 아니라 I2C 디지털 통신으로 값을 받습니다. 배선과 읽는 방법만 다르고, 보정·세기 계산·임계값 판단은 위와 완전히 동일합니다.

센서 핀아두이노 우노
VCC5V 또는 3.3V (모듈 표시를 따를 것)
GNDGND
SDAA4
SCLA5
A4·A5는 이제 못 씁니다

I2C는 A4(SDA)와 A5(SCL)를 독점해서 씁니다. 이 두 핀은 더 이상 아날로그 입력으로 쓸 수 없습니다. 다른 아날로그 센서가 있다면 A0~A3에 꽂으세요.

1단계 · 라이브러리 설치

I2C 센서는 라이브러리를 쓰면 아주 간단해집니다. Arduino IDE 왼쪽의 책 모양 아이콘(라이브러리 관리)을 누르고, 검색창에 QMC5883LCompass 를 입력해 설치를 누르세요. (메뉴로는 스케치 → 라이브러리 포함하기 → 라이브러리 관리)

왜 이 라이브러리인가

시중에서 파는 저가 3축 자기장 모듈(GY-271 등)에 들어 있는 칩이 대부분 QMC5883L입니다. 설치 한 번이면 끝나고, 값을 읽는 코드가 세 줄입니다.

2단계 · 코드는 이게 전부입니다

MagI2C.ino
#include <QMC5883LCompass.h>

QMC5883LCompass compass;

void setup() {
  Serial.begin(9600);
  compass.init();          // 센서 시작 — 초기 설정을 알아서 해 줍니다
}

void loop() {
  compass.read();          // 센서에서 새 값을 가져옴

  int x = compass.getX();
  int y = compass.getY();
  int z = compass.getZ();

  Serial.print("X:");   Serial.print(x);
  Serial.print(",Y:");  Serial.print(y);
  Serial.print(",Z:");  Serial.println(z);

  delay(50);
}

앞의 아날로그 코드와 비교해 보세요. analogRead(A0) 이 compass.getX() 로 바뀌었을 뿐, 구조가 완전히 같습니다. 센서가 복잡해져도 우리가 쓰는 코드는 그대로인 것, 이게 라이브러리를 쓰는 이유입니다.

명령하는 일

compass.read()센서에서 새 값을 가져옵니다. 이걸 부르지 않으면 getX()가 계속 같은 값만 돌려줍니다.
compass.getX()가져온 값 중 X축. getY(), getZ()도 같습니다.
compass.getAzimuth()덤. 방위각을 0~359도로 바로 계산해 줍니다. 나침반 만들 때 쓰세요.

라이브러리 없이 직접 읽기 — 학교 노트북에 설치가 막혀 있을 때만

라이브러리를 설치할 수 없는 환경이라면 Wire만으로도 읽을 수 있습니다. 수업에서는 위의 라이브러리 방식을 쓰세요. 아래는 비상용입니다.

QMC5883L · 0x0D
#include <Wire.h>

const byte QMC = 0x0D;

void writeReg(byte reg, byte value) {
  Wire.beginTransmission(QMC);
  Wire.write(reg);
  Wire.write(value);
  Wire.endTransmission();
}

// 두 바이트를 붙여 부호 있는 값으로 (QMC는 하위 바이트가 먼저)
int16_t read16LE() {
  byte lo = Wire.read();
  byte hi = Wire.read();
  return (int16_t)(((uint16_t)hi << 8) | lo);
}

void setup() {
  Serial.begin(9600);
  Wire.begin();
  writeReg(0x0B, 0x01);   // SET/RESET 주기 — 반드시 먼저
  writeReg(0x09, 0x1D);   // 연속 측정 · 200Hz · ±8가우스
  delay(100);
}

void loop() {
  Wire.beginTransmission(QMC);
  Wire.write(0x00);            // 데이터 시작 주소
  Wire.endTransmission();
  Wire.requestFrom((uint8_t)QMC, (uint8_t)6);

  if (Wire.available() >= 6) {
    int16_t x = read16LE();
    int16_t y = read16LE();
    int16_t z = read16LE();

    Serial.print("X:");   Serial.print(x);
    Serial.print(",Y:");  Serial.print(y);
    Serial.print(",Z:");  Serial.println(z);
  }
  delay(50);
}

HMC5883L(0x1E)은 설정 레지스터와 바이트 순서가 다릅니다. 0x00←0x70, 0x01←0x20, 0x02←0x00 으로 초기화하고, 데이터는 0x03번지부터 상위 바이트가 먼저, 순서는 X → Z → Y입니다. (Y와 Z가 바뀌어 나오는 게 이것 때문입니다.)

증상확인할 것
값이 계속 0compass.read()를 빼먹었거나, 칩이 달라 라이브러리가 맞지 않습니다. 스캐너로 주소를 확인하세요.
스캐너에 아무것도 안 뜸SDA와 SCL이 바뀌어 꽂혔거나 VCC·GND가 빠졌습니다. SDA=A4, SCL=A5입니다.
값이 안 변함loop() 안에서 read()를 부르고 있는지 확인하세요. setup()에만 있으면 값이 고정됩니다.
컴파일 오류라이브러리 버전에 따라 함수 이름이 다릅니다. 파일 → 예제에서 설치된 버전의 예제를 여세요.
값이 가끔 튀거나 멈춤점퍼선이 길거나 접촉이 나쁩니다. I2C는 배선 길이에 민감하니 짧고 단단히 꽂으세요.

값이 이상할 때

증상원인과 해결
값이 0 또는 1023에 붙어 있음 배선 문제입니다. ① VCC·GND가 제대로 연결됐는지 ② 출력 핀이 A0~A2에 맞게 꽂혔는지 ③ 센서가 3.3V 전용인데 5V를 물린 건 아닌지 확인하세요.
값이 계속 심하게 떨림 정상 범위 내의 노이즈일 수 있습니다. readAverage()처럼 여러 번 읽어 평균을 내세요. 점퍼선이 길거나 헐거워도 심해집니다.
노트북 근처에서 값이 튐 스피커·모터·전원 어댑터에는 자석이나 강한 전류가 있습니다. 센서를 그것들과 떨어뜨려 두고 측정하세요. 이건 고장이 아니라 센서가 제대로 동작한다는 증거입니다.
세 축이 모두 똑같이 움직임 세 점퍼선이 실제로는 같은 핀에 꽂혀 있을 가능성이 큽니다. 브레드보드의 세로줄을 확인하세요.
플로터에 선이 안 그려짐 출력 형식이 이름:값,이름:값 이 아니거나, 속도가 9600이 아니거나, 글자만 있는 println이 섞여 있습니다.
세기가 음수/이상한 큰 값 (long) 형변환을 빠뜨려 int 범위를 넘친 것입니다. 위 표의 설명을 확인하세요.

프로젝트로 확장하기

여기까지가 뼈대입니다. 이제 출력 쪽만 바꾸면 서로 다른 장치가 됩니다.

① 문 열림 감지기

문틀에 센서를, 문에 자석을 붙입니다. 문이 닫혀 있으면 세기가 크고, 열리면 급격히 작아집니다. 세기가 임계값 아래로 떨어지면 부저를 울리세요. 판단의 부등호 방향만 반대로 하면 됩니다.

② 세기에 따라 밝기가 변하는 LED

자석이 가까울수록 LED가 밝아지게 만들어 보세요. 3강의 analogWrite()와 9번 핀을 씁니다.

힌트 보기
map + constrain
// 세기 0~300 을 밝기 0~255 로 비례 변환
int level = map(strength, 0, 300, 0, 255);
level = constrain(level, 0, 255);   // 범위 밖으로 나가지 않게
analogWrite(9, level);

map(값, 원래최소, 원래최대, 바꿀최소, 바꿀최대)는 범위를 비례해서 옮겨 주는 함수입니다. 센서 값을 다룰 때 아주 자주 씁니다.

③ 자석 나침반

X와 Y 값으로 방향(각도)을 계산해 시리얼로 출력해 보세요. 힌트: float angle = atan2(y, x) * 180.0 / PI; 로 −180°~180° 각도가 나옵니다. 음수면 360을 더해 0~360°로 바꾸세요.

④ 신호등과 합치기

6강의 신호등에서 버튼 대신 자기장 센서를 쓰세요. 자석이 달린 물체(차·자전거)가 지나가면 신호가 바뀝니다. digitalRead(BUTTON) == LOW 자리에 strength > THRESHOLD를 넣기만 하면 됩니다. 입력만 바꿔 끼우면 되는 것이 이 구조의 힘입니다.

⑤ 회전수 측정기 (심화)

바퀴에 자석을 하나 붙이고, 자석이 지나갈 때마다 횟수를 셉니다. 1분에 몇 바퀴(RPM)인지 계산해 출력해 보세요. 5강의 “변화 순간만 잡아내기”와 millis()를 함께 씁니다.
