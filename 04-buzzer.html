04강 · 출력

버저 출력

LED가 빛이라는 출력이었다면, 부저는 소리라는 출력입니다. 핀에 신호를 내보내는 방식은 똑같습니다. 다만 소리는 “얼마나 빠르게 껐다 켜느냐”로 높낮이가 정해집니다.

이 강의를 마치면

  • 능동 부저와 수동 부저를 구분하고 올바르게 연결할 수 있다
  • tone()과 noTone()으로 원하는 음을 낼 수 있다
  • 주파수와 음높이의 관계를 설명할 수 있다
  • 배열과 반복문으로 멜로디를 연주할 수 있다
입력—

이번 강의에서는 쓰지 않습니다

→
연산주파수 계산

어떤 음을 얼마나 길게 낼지 정합니다

→
출력부저

tone()으로 소리를 냅니다

준비물

  • 아두이노 우노USB 케이블 포함

부저는 두 종류입니다

겉모습이 거의 같아서 자주 헷갈립니다. 하지만 동작 방식이 완전히 다릅니다. 키트에 어떤 것이 들어 있는지 먼저 확인하세요.

능동 부저 (Active)수동 부저 (Passive)
소리 내는 법digitalWrite(7, HIGH)만 해도 삐— 소리tone(7, 주파수)로 주파수를 줘야 함
음 높이고정 — 한 가지 소리만 가능자유 — 도레미 연주 가능
겉모습바닥이 검은 스티커로 막혀 있음. 키가 조금 큼바닥에 초록 회로 기판이 보임
극성있음 — 긴 다리가 (+)대부분 없음 (있으면 (+) 표시를 따름)
이 수업에서알람·경고음 정도이걸 씁니다 — 멜로디를 만들 수 있어서
어떤 건지 모르겠다면

일단 tone(7, 440)을 올려 보세요. 수동 부저면 “라” 음이 정확히 나고, 능동 부저면 원래 정해진 소리가 납니다. 둘 다 소리는 나므로 회로가 잘못된 건 아닙니다.

회로 만들기

시작 전

USB 케이블을 뽑으세요. 배선이 끝난 뒤에 다시 꽂습니다.

LED보다 훨씬 간단합니다. 부저 (+) → 7번 핀, 부저 (−) → GND. 끝입니다. 수동 부저는 소비 전류가 작아서 저항 없이 바로 연결해도 됩니다.

순서연결
1부저 (+) → 브레드보드 → 아두이노 7번 핀
2부저 (−) → 브레드보드 → 아두이노 GND
교실이 시끄러워진다면

부저와 핀 사이에 100Ω ~ 1kΩ 저항을 하나 끼우면 소리가 확실히 작아집니다. 저항이 클수록 조용해집니다.

첫 소리 내기

Beep.ino
const int BUZZER = 7;

void setup() {
  pinMode(BUZZER, OUTPUT);
}

void loop() {
  tone(BUZZER, 440);   // 440Hz = '라' 음을 계속 냄
  delay(500);          // 0.5초 유지
  noTone(BUZZER);      // 소리 끔
  delay(500);          // 0.5초 조용히
}
명령하는 일
tone(핀, 주파수)그 핀에서 해당 주파수의 소리를 계속 냅니다. noTone()을 부르기 전까지 멈추지 않습니다.
tone(핀, 주파수, 길이)정해진 시간(ms) 동안만 소리를 냅니다. 시간이 지나면 자동으로 멈춥니다.
noTone(핀)그 핀의 소리를 끕니다.
tone()의 세 번째 인자는 delay()가 아닙니다

tone(7, 440, 500)은 “500ms 동안 소리를 내라”고 예약만 하고 바로 다음 줄로 넘어갑니다. 소리가 끝날 때까지 기다리려면 delay(500)을 따로 써 줘야 합니다. 이걸 빼먹으면 음이 순식간에 지나가 버립니다.

주파수와 음높이

소리는 공기의 떨림입니다. 1초에 몇 번 떠느냐가 주파수(Hz)이고, 이 숫자가 클수록 높은 소리가 납니다. 부저는 아두이노가 핀을 아주 빠르게 껐다 켜면서 그 떨림을 만들어 냅니다. LED를 초당 440번 깜빡이는 것과 원리가 똑같습니다 — 다만 너무 빨라서 눈에는 안 보이고 귀에는 들리는 것뿐입니다.

음계 연주하기

배열에 음을 넣고 반복문으로 하나씩 꺼내 연주합니다. 3강에서 본 for문이 그대로 쓰입니다.

Scale.ino
const int BUZZER = 7;

// 도 레 미 파 솔 라 시 도'
const int scale[8] = {262, 294, 330, 349, 392, 440, 494, 523};

void setup() {
  pinMode(BUZZER, OUTPUT);
}

void loop() {
  for (int i = 0; i < 8; i++) {
    tone(BUZZER, scale[i]);   // i번째 음을 냄
    delay(350);               // 소리를 유지할 시간
  }
  noTone(BUZZER);
  delay(1500);                // 한 바퀴 돌고 잠시 쉼
}
여기서 배열이 왜 좋은가

배열을 안 쓰면 tone(BUZZER, 262); delay(350); 를 8번 써야 합니다. 배열을 쓰면 음을 추가하고 싶을 때 중괄호 안에 숫자만 하나 더 넣으면 됩니다. (배열 크기 [8]도 함께 고쳐야 합니다.)

멜로디 연주하기

실제 곡을 연주하려면 음 높이뿐 아니라 음의 길이도 필요합니다. 배열 두 개를 나란히 쓰면 됩니다. 이 구조는 6강 신호등에서 “핀 배열 + 시간 배열”로 다시 나옵니다.

Melody.ino
const int BUZZER = 7;

// 학교종이 땡땡땡 — 솔솔라라 솔솔미 솔솔미미레
const int NOTE_COUNT = 14;

const int melody[NOTE_COUNT] = {
  392, 392, 440, 440, 392, 392, 330,
  392, 392, 330, 330, 294, 294, 0     // 0 = 쉼표
};

const int beats[NOTE_COUNT] = {
  4, 4, 4, 4, 4, 4, 8,
  4, 4, 4, 4, 4, 4, 8
};

const int TEMPO = 90;   // 한 박자의 길이(ms). 작을수록 빨라집니다

void setup() {
  pinMode(BUZZER, OUTPUT);
}

void playMelody() {
  for (int i = 0; i < NOTE_COUNT; i++) {
    int duration = beats[i] * TEMPO;

    if (melody[i] == 0) {
      noTone(BUZZER);          // 쉼표는 소리를 끄고 기다리기만
    } else {
      tone(BUZZER, melody[i]);
    }

    delay(duration);
    noTone(BUZZER);
    delay(30);                 // 음 사이를 살짝 띄워야 또렷하게 들립니다
  }
}

void loop() {
  playMelody();
  delay(2000);
}
음이 뭉개져서 들린다면

음과 음 사이에 noTone() + 짧은 delay(30)을 넣어 끊어 주는 것이 핵심입니다. 이게 없으면 같은 음이 두 번 연달아 나올 때 하나로 이어져 들립니다.

알아둘 제약

제약내용
한 번에 한 핀만 tone()은 동시에 하나의 핀에서만 동작합니다. 부저 두 개로 화음을 내는 것은 불가능합니다.
3번·11번 핀 PWM 충돌 tone()을 쓰는 동안 3번과 11번 핀의 analogWrite()가 동작하지 않습니다. 같은 내부 타이머를 쓰기 때문입니다. LED 밝기 조절과 소리를 함께 쓴다면 5·6·9·10번 핀을 쓰세요.
delay()와 같은 한계 멜로디를 연주하는 동안 delay()가 계속 실행되므로 버튼을 눌러도 반응하지 않습니다. 6강의 millis()에서 이 문제를 다룹니다.
낼 수 있는 범위 약 31 ~ 65535 Hz. 다만 사람이 듣는 범위는 대략 20 ~ 20,000Hz이고, 작은 부저는 1000 ~ 4000Hz에서 가장 크게 울립니다.

도전과제

① 사이렌 만들기

주파수를 400에서 1200까지 올렸다가 다시 내리는 것을 반복해 구급차 소리를 만들어 보세요.

답 보기
Siren.ino
void loop() {
  for (int f = 400; f <= 1200; f += 10) {
    tone(BUZZER, f);
    delay(5);
  }
  for (int f = 1200; f >= 400; f -= 10) {
    tone(BUZZER, f);
    delay(5);
  }
}

② LED와 함께 쓰기

음이 바뀔 때마다 LED도 함께 깜빡이게 만들어 보세요. 3강의 LED 회로를 그대로 두고 부저만 추가하면 됩니다. 출력을 두 개 동시에 다루는 첫 연습입니다.

③ 내가 아는 곡 옮기기

위 melody[]와 beats[]를 고쳐서 아는 곡을 연주해 보세요. 계이름만 알면 위의 주파수 표를 보고 숫자로 바꿀 수 있습니다. (반짝반짝 작은별: 도도솔솔라라솔)

④ 경고음 함수 만들기

“삐 삐 삐” 세 번 울리는 alarm() 함수를 만들어 보세요. 6강 신호등에서 실제로 쓰게 됩니다.

답 보기
alarm()
void alarm(int times) {
  for (int i = 0; i < times; i++) {
    tone(BUZZER, 1200);
    delay(120);
    noTone(BUZZER);
    delay(120);
  }
}

// 사용: alarm(3);
