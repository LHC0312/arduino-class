3차원 자기장 시각화

7강에서는 한 지점의 X·Y·Z를 읽었습니다. 이번에는 여러 지점에서 잰 값을 한꺼번에 다룹니다. 숫자만 봐서는 알 수 없던 자기장의 모양이, 3차원 화살표로 그리는 순간 눈에 보입니다.

이 강의를 마치면

  • 측정 지점의 위치(x, y)와 그 지점의 자기장(x, y, z)을 구분해서 다룰 수 있다
  • 코랩에서 quiver로 3차원 벡터를 그릴 수 있다
  • 세기를 계산해 히트맵으로 분포를 볼 수 있다
  • 거리에 따라 자기장이 얼마나 빠르게 약해지는지 확인할 수 있다
  • sklearn 세 줄로 자기장 패턴을 맞히는 프로그램을 만들 수 있다
입력9개 지점 × 3축

값 27개가 한 세트

→
연산시각화 · 패턴 비교

그림으로 보고, 가장 비슷한 것을 찾습니다

출력그래프 · 추정 결과

3D 화살표, 히트맵, 예측값

이 강의의 데이터는 실제 측정값입니다

아래에 나오는 숫자는 아두이노와 QMC5883L로 직접 측정한 탐구 자료입니다. 예제용으로 꾸며낸 값이 아니어서, 이론과 딱 맞지 않는 부분도 그대로 들어 있습니다. 그 어긋남을 확인하는 것도 이 강의의 목적입니다.

한 지점이 아니라 여러 지점

자석 하나를 놓고 그 위 어느 한 곳에서만 자기장을 재면, 값 세 개(x, y, z)를 얻습니다. 그런데 자석을 다른 곳으로 옮겨도 그 한 지점의 값은 비슷하게 나올 수 있습니다. 한 곳만 봐서는 자석이 어디 있는지 알 수 없다는 뜻입니다.

그래서 센서를 여러 지점으로 옮겨 가며 잽니다. 9개 지점에서 각각 세 축을 재면 9 × 3 = 27개의 값이 나옵니다. 이 27개의 조합을 자기장 패턴이라고 부르겠습니다. 자석의 위치가 달라지면 이 패턴 전체가 달라집니다.

지문에 비유하면

손가락 한 점만 보면 누구 것인지 알 수 없지만, 무늬 전체를 보면 구분됩니다. 자기장 패턴도 마찬가지입니다. 값 하나가 아니라 27개의 조합이 자석 위치의 지문 역할을 합니다.

측정 좌표 정하기

센서를 아무 데나 옮기면 나중에 비교할 수 없습니다. 미리 정한 격자점에서만 재야 합니다. 여기서는 4cm 간격의 3×3 격자 9곳을 씁니다. 왼쪽 위부터 M1, 오른쪽 아래가 M9입니다.

두 가지 좌표를 헷갈리지 마세요
무엇값의 개수뜻
지점의 위치2개 (x, y)센서를 어디에 놓았는지. 단위는 cm. 우리가 정하는 값입니다.
그 지점의 자기장3개 (x, y, z)센서가 읽어낸 값. 단위 없는 원자료입니다.

3차원으로 보기

아래는 실제 측정한 데이터입니다. 자석은 격자 한가운데 아래에 두고, 자석까지의 거리를 10cm에서 4cm까지 바꿔가며 9개 지점을 모두 쟀습니다. 파란 점이 측정 지점, 주황 화살표가 그 지점의 자기장 방향과 크기입니다.

자석까지 거리
눈여겨볼 것
  • 화살표가 제각각 다른 방향을 가리킵니다. 자석이 가운데 있어도 주변 자기장은 휘어져 있기 때문입니다.
  • 거리를 줄이면 세기가 급격히 커집니다. 10cm에서 38.8이던 것이 4cm에서는 871.2가 됩니다.
  • 4cm에서는 특정 지점의 값이 유독 크게 튑니다. 자석에 너무 가까워지면 측정이 불안정해진다는 신호입니다.

코랩에 데이터 넣기

이제 같은 데이터를 코랩에서 직접 다뤄 봅니다. 파일 → 새 노트로 시작하세요.

셀 1 · 데이터
import numpy as np
import matplotlib.pyplot as plt

# 측정 지점 M1~M9 의 위치 (cm)
points = np.array([
    [-4,  4], [0,  4], [4,  4],
    [-4,  0], [0,  0], [4,  0],
    [-4, -4], [0, -4], [4, -4],
])

# 각 지점에서 잰 자기장 (x, y, z) — 자석까지 10 cm
field = np.array([
    [ 20.47,  -3.77,   5.65],
    [ 20.62, -19.46,  -0.89],
    [  8.92, -16.96, -13.40],
    [ 13.05,  -7.91,  25.48],
    [  9.40, -32.76,  18.48],
    [ -0.58, -28.42,  -6.96],
    [ -6.99,  -0.66,  21.99],
    [-14.10, -21.66,  19.91],
    [-16.21, -19.00,  -3.78],
])

print("지점 위치:", points.shape)
print("자기장  :", field.shape)
출력
지점 위치: (9, 2) 자기장 : (9, 3)

(9, 2)는 “9줄 × 2칸”이라는 뜻입니다. 지점은 위치가 2개(x, y), 자기장은 값이 3개(x, y, z)라서 모양이 다릅니다.

3차원 화살표로 그리기

이 강의의 핵심입니다. matplotlib의 quiver는 “어디에서(x, y, z) 어느 쪽으로(u, v, w)” 를 주면 화살표를 그려줍니다. 측정 지점이 어디에서, 자기장이 어느 쪽으로에 들어갑니다.

셀 2 · 3D 화살표
fig = plt.figure(figsize=(7, 6))
ax = fig.add_subplot(projection='3d')      # 3차원 그래프

# 화살표가 시작하는 곳 = 측정 지점
x = points[:, 0]
y = points[:, 1]
z = np.zeros(9)                # 센서는 모두 같은 높이라 z = 0

# 화살표가 향하는 쪽 = 자기장
u, v, w = field[:, 0], field[:, 1], field[:, 2]

# 가장 긴 화살표가 3 cm 가 되도록 길이를 맞춥니다
scale = 3.0 / np.linalg.norm(field, axis=1).max()

ax.quiver(x, y, z, u, v, w, length=scale, color='#c0503c')
ax.scatter(x, y, z, color='#3c6ea8', s=40)              # 측정 지점
ax.scatter([0], [0], [-10], color='black', s=150, marker='s')   # 자석

ax.set_xlabel('x (cm)')
ax.set_ylabel('y (cm)')
ax.set_zlabel('z (cm)')
ax.set_zlim(-11, 5)
plt.show()
코랩에서는 그래프를 돌려볼 수 있습니다

셀 맨 위에 %matplotlib widget 을 넣으면 마우스로 드래그해서 각도를 바꿀 수 있습니다. 잘 안 되면 대신 ax.view_init(elev=25, azim=45) 처럼 보는 각도를 숫자로 지정하고 여러 각도를 실행해 보세요.

length는 왜 계산해서 넣을까

자기장 값(수십~수백)을 그대로 화살표 길이로 쓰면, 4cm 데이터에서는 화살표가 화면 밖으로 나갑니다. 그래서 3.0 ÷ 가장 큰 세기 로 축척을 계산해 가장 긴 화살표를 3cm에 맞췄습니다. 데이터를 바꿔도 코드를 안 고쳐도 됩니다. 대신 서로 다른 그림의 화살표 길이를 직접 비교하면 안 됩니다. 축척이 다르니까요.

세기로 보기

화살표는 방향까지 보여주지만 한눈에 비교하기는 어렵습니다. 세 축을 하나의 숫자로 합치면 “어디가 더 센가”를 바로 볼 수 있습니다. 7강에서 쓴 그 계산입니다.

셀 3 · 세기 계산
# 세기 = √(x² + y² + z²)  — norm 이 이 계산을 해 줍니다
strength = np.linalg.norm(field, axis=1)

for i, s in enumerate(strength):
    print(f"M{i+1}  세기 {s:6.1f}")

print()
print("가장 센 곳: M", strength.argmax() + 1, " 세기", round(strength.max(), 1))
출력
M1 세기 21.6 M2 세기 28.4 M3 세기 23.4 M4 세기 29.7 M5 세기 38.8 M6 세기 29.3 M7 세기 23.1 M8 세기 32.6 M9 세기 25.3 가장 센 곳: M 5 세기 38.8

가운데인 M5가 가장 셉니다. 자석이 바로 그 아래에 있으니 당연한 결과이고, 측정이 제대로 됐다는 확인이기도 합니다.

위에서 본 분포 — 히트맵

셀 4 · 히트맵
grid = strength.reshape(3, 3)     # 9개를 3×3 판 모양으로 되돌림

plt.figure(figsize=(5, 4.5))
plt.imshow(grid, cmap='YlOrRd', extent=[-6, 6, -6, 6])
plt.colorbar(label='strength')

for i in range(9):
    plt.text(points[i, 0], points[i, 1], f"M{i+1}",
             ha='center', va='center', fontsize=9)

plt.xlabel('x (cm)')
plt.ylabel('y (cm)')
plt.title('Field strength (top view)')
plt.show()

reshape(3, 3)은 일렬로 늘어선 9개를 3줄씩 끊어 원래 판 모양으로 되돌립니다. M1·M2·M3가 첫 줄, M4·M5·M6이 둘째 줄이 되므로 실제 배치와 그대로 맞습니다.

거리에 따라 어떻게 변할까

자석에서 멀어지면 자기장은 약해집니다. 그런데 얼마나 빠르게 약해질까요? 이론적으로 막대자석의 자기장은 거리의 세제곱에 반비례합니다. 거리가 절반이 되면 약 8배 세지는 셈입니다. 실제 측정이 그런지 확인해 봅시다.

셀 5 · 거리별 비교
fields = {}
fields[10] = field       # 위에서 입력한 것

fields[8] = np.array([
    [ 33.68, -10.23,  14.70], [ 38.89, -37.51,  -3.58], [  8.25, -19.54,  -8.63],
    [ 22.21,  15.84,  37.52], [ -3.83, -46.18, -16.21], [ -4.49, -42.56,  -4.43],
    [-10.42,   6.72,  35.60], [-31.24, -37.93,  43.98], [-24.67, -25.30,  -1.42],
])
fields[6] = np.array([
    [ 56.48,  10.55,   6.23], [ 84.86, -51.08, -12.55], [ -0.54,   0.00,   0.24],
    [ 62.64,   8.16,  95.19], [ 59.50, -58.76, 101.05], [ -7.73, -90.37, -23.90],
    [-20.24,  23.84,  74.53], [-69.09, -60.49,  92.38], [-54.70, -45.09,  -2.25],
])
fields[4] = np.array([
    [171.08, -11.21, -78.90], [ 17.11, -35.39, -62.40], [ 26.14, -37.26, -72.24],
    [ 69.77,  33.12,  98.56], [-60.64,-218.85,  90.10], [-109.34,-13.85, 468.50],
    [-179.10,296.35, 472.61], [-715.49,-151.38,473.42], [-344.59,-94.12,   7.54],
])

distances = [10, 8, 6, 4]
peaks = [np.linalg.norm(fields[d], axis=1).max() for d in distances]

for d, s in zip(distances, peaks):
    ratio = s / peaks[0]
    theory = (10 / d) ** 3
    print(f"{d:2d} cm  최대 세기 {s:7.1f}   실제 {ratio:5.2f}배   이론 {theory:5.2f}배")

plt.figure(figsize=(6, 4))
plt.plot(distances, peaks, 'o-', color='#c0503c')
plt.xlabel('distance (cm)')
plt.ylabel('max strength')
plt.gca().invert_xaxis()          # 가까울수록 오른쪽으로
plt.grid(alpha=0.3)
plt.show()
출력
10 cm 최대 세기 38.8 실제 1.00배 이론 1.00배 8 cm 최대 세기 65.9 실제 1.70배 이론 1.95배 6 cm 최대 세기 131.2 실제 3.38배 이론 4.63배 4 cm 최대 세기 871.2 실제 22.47배 이론 15.62배
이론과 안 맞는데, 실패한 걸까?

아닙니다. 이런 어긋남을 확인하는 것이 실험입니다. 읽어야 할 것은 두 가지입니다.

  • 8cm·6cm는 이론보다 작게 나왔습니다. “거리의 세제곱” 법칙은 자석에서 충분히 멀 때만 맞습니다. 자석 크기에 비해 가까우면 어긋납니다.
  • 4cm는 이론보다 훨씬 크게 나왔습니다. 자석이 너무 가까워 값이 불안정해졌을 가능성이 큽니다. 그래서 실제 탐구에서는 4cm를 쓰지 않고 더 먼 거리를 골랐습니다.
데이터를 의심하는 습관

6cm 자료의 M3를 보세요. (-0.54, 0.00, 0.24) — 주변 지점은 수십에서 백 단위인데 이 지점만 거의 0입니다. 센서가 제대로 안 놓였거나 측정이 빠졌을 가능성이 큽니다. 이런 지점을 찾아내는 것도 시각화의 목적입니다. 그래프를 그리면 표에서는 안 보이던 게 튀어나옵니다.

패턴 맞히기 · sklearn

이제 거꾸로 해봅시다. 자기장 패턴만 보고, 자석이 얼마나 떨어져 있었는지 알아맞히는 프로그램입니다. 방법은 간단합니다. 이미 알고 있는 4개의 패턴과 하나씩 비교해서, 가장 비슷한 것을 고르면 됩니다.

“가장 비슷한 것 고르기”는 sklearn에 이미 들어 있습니다. KNeighborsClassifier(n_neighbors=1) 이 정확히 그 일을 합니다.

셀 6 · 패턴 맞히기
from sklearn.neighbors import KNeighborsClassifier

# 27개 값을 한 줄로 펴서 학습 자료로 만듭니다
X = np.array([fields[d].flatten() for d in distances])   # (4, 27)
y = np.array(distances)                                  # [10, 8, 6, 4]

model = KNeighborsClassifier(n_neighbors=1)   # 가장 비슷한 것 1개를 고름
model.fit(X, y)

# 6 cm 자료를 조금 어긋나게 만들어 '정답을 모르는 자료' 를 흉내냅니다.
# (다시 측정하면 값이 똑같이 나오지는 않으니까요)
unknown = fields[6] * 1.05 + 2.0

answer = model.predict(unknown.flatten().reshape(1, -1))
print("추정 거리:", answer[0], "cm")
출력
추정 거리: 6 cm

안에서 무슨 일이 일어나는가

fit과 predict 두 줄 안에서 벌어지는 일은 이렇습니다. 직접 계산해 보면 이해가 확실해집니다.

셀 7 · 직접 계산해 확인
for d in distances:
    mse = np.mean((fields[d] - unknown) ** 2)     # 평균제곱오차
    print(f"{d:2d} cm 와의 차이: {mse:10.1f}")
출력
10 cm 와의 차이: 1916.2 8 cm 와의 차이: 1605.9 6 cm 와의 차이: 12.8 4 cm 와의 차이: 45890.7

6cm와의 차이가 압도적으로 작습니다. 그래서 6cm를 답으로 고른 것입니다. 그리고 두 번째로 작은 8cm(1605.9)와의 간격이 크게 벌어져 있을수록 그 판단을 믿을 만합니다. 1위와 2위가 엇비슷하면 헷갈리고 있다는 뜻이므로, 이 간격도 함께 봐야 합니다.

평균제곱오차와 1-최근접이웃은 같은 것입니다

평균제곱오차가 가장 작은 것을 고르는 것과, 27차원 공간에서 가장 가까운 점을 고르는 것은 완전히 같은 계산입니다. 거리를 제곱하고 개수로 나눈 것이 평균제곱오차이기 때문입니다. 그래서 직접 짠 코드와 sklearn의 결과가 항상 일치합니다. sklearn을 쓰면 세 줄이면 되는 일이고, 나중에 다른 방법으로 바꾸기도 쉽습니다.

자석의 위치를 맞히려면

여기서는 거리를 맞혔지만, 위치를 맞히는 것도 코드가 똑같습니다. 자석을 9개 후보 위치 P1~P9에 하나씩 놓고 27개 값을 재서 X를 (9, 27) 로, y를 ['P1', …, 'P9'] 로 바꾸기만 하면 됩니다. 고쳐야 할 줄은 두 줄뿐입니다.

② 이상한 지점 찾아내기

6cm 자료의 히트맵을 그려서 M3가 얼마나 튀는지 눈으로 확인해 보세요. 그리고 M3를 이웃 지점들의 평균으로 바꾼 뒤 다시 그려 비교해 보세요.

③ 측정이 얼마나 정확해야 할까

측정값이 흔들려도 계속 맞힐 수 있을까요? 잡음을 조금씩 키우며 언제부터 틀리기 시작하는지 찾아보세요.

여러 번 시험하기
rng = np.random.default_rng(0)

for noise in [0.05, 0.1, 0.2, 0.4, 0.8]:
    correct = 0
    for i in range(100):
        u = fields[6] * (1 + rng.normal(0, noise, size=(9, 3)))
        if model.predict(u.flatten().reshape(1, -1))[0] == 6:
            correct += 1
    print(f"잡음 {noise:.2f} → 정확도 {correct}%")

rng.normal(0, noise, …)은 무작위로 값을 흔드는 것입니다. 측정이 얼마나 정확해야 이 방법이 통하는지 알려주는 실험이고, 정확도가 무너지는 지점이 곧 이 방법의 한계입니다.

④ 지점을 줄여보기 (심화)

9개 지점을 다 쓰지 않고 가운데 M5 하나만, 또는 네 모서리 M1·M3·M7·M9만 써도 맞힐 수 있을까요? fields[d][[0, 2, 6, 8]] 처럼 원하는 줄만 골라내서 같은 과정을 반복해 보세요. 센서를 몇 개까지 줄일 수 있는지 알아보는, 실제 연구에서 쓰는 방법입니다.
