# 아두이노 기초 — 수업 자료

중·고등 및 입문자를 대상으로 한 4차시 아두이노 실습 수업용 정적 웹사이트입니다.

## 커리큘럼

| # | 강의 | 내용 |
|---|------|------|
| 01 | 아두이노란? | 보드 구조, 핀 역할, 디지털/아날로그, `setup()` · `loop()` |
| 02 | IDE 설치와 첫 업로드 | Arduino IDE 2.x 설치, 보드·포트 설정, Blink, 시리얼 모니터 |
| 03 | LED 제어 | 브레드보드, LED 극성, 저항 계산, `digitalWrite` · `analogWrite` |
| 04 | 신호등 만들기 | 함수, 배열, `for` 반복, `millis()` 논블로킹 제어 |

## 구성

빌드 도구 없이 동작하는 순수 정적 사이트입니다.

```
index.html          강의 목록 · 준비물 · 안전 수칙
01-arduino.html     아두이노란?
02-ide.html         IDE 설치와 첫 업로드
03-led.html         LED 제어
04-traffic.html     신호등 만들기
assets/style.css    스타일
assets/site.js      구문 강조 · 진도 저장 · 시뮬레이터
```

- 회로도와 보드 그림은 모두 인라인 SVG라 확대해도 깨지지 않고, 다크 모드에서 라벨 색이 함께 바뀝니다.
- 진도 체크와 체크리스트 상태는 브라우저의 `localStorage`에 저장됩니다.
- 인쇄용 스타일이 있어 그대로 유인물로 출력할 수 있습니다.

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 준비물 (학생 1인 기준)

아두이노 우노 R3 · USB A-B 케이블 · 브레드보드 · 점퍼선 10개 이상 ·
LED 빨강/노랑/초록 · 220Ω 저항 3개
