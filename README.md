# 아두이노 기초 — 수업 자료

중·고등 및 입문자를 대상으로 한 8차시 아두이노 실습 수업용 정적 웹사이트입니다.

**https://lhc0312.github.io/arduino-class/**

## 구성 원칙 — 입력 → 연산 → 출력

아두이노가 하는 일은 늘 같습니다. 바깥 상태를 **읽고(입력)**, **판단하고(연산)**, 무언가를 **움직입니다(출력)**.
커리큘럼은 이 세 칸을 하나씩 채워 나가는 순서로 짜여 있습니다.

| # | 강의 | 구분 | 내용 |
|---|------|------|------|
| 01 | 아두이노란? | 개념 | 보드 구조, 핀 역할, 디지털/아날로그, `setup()` · `loop()` |
| 02 | IDE 설치와 첫 업로드 | 환경 | Arduino IDE 2.x 설치, 보드·포트 설정, Blink, 시리얼 모니터 |
| 03 | LED 제어 | **출력** | 브레드보드, LED 극성, 저항 계산, `digitalWrite` · `analogWrite` |
| 04 | 버저 출력 | **출력** | 능동/수동 부저, `tone()`, 주파수와 음높이, 배열로 멜로디 |
| 05 | 버튼 입력 | **입력** | 택트 스위치, 플로팅, 풀다운 · `INPUT_PULLUP`, 토글과 디바운스 |
| 06 | 신호등 만들기 | 종합 | 함수·배열·`millis()`, **상태 기계**로 만드는 보행자 신호등 |
| 07 | 프로젝트와 연계하기 | **입력** | 자기장 센서 `analogRead` X·Y·Z, 시리얼 플로터, 보정·필터·임계값 |
| 08 | 코랩으로 선형회귀 | **연산** | 구글 코랩, 최소제곱법, `np.polyfit`·scikit-learn, R², 센서 보정식을 아두이노로 |

06강 마지막에서 **버튼(입력) → 상태 전이(연산) → LED 3개 + 부저(출력)** 가 하나로 합쳐지고,
07강에서 버튼 자리에 센서를 끼워 넣어 실제 프로젝트로 확장합니다.
08강은 그 센서가 내놓는 숫자가 **실제로 몇 도인지**를 데이터로 찾아내, 구한 식을 다시 아두이노에 돌려놓습니다.

## 핀 배치 (전 강의 공통)

| 핀 | 용도 |
|----|------|
| `2` | 택트 스위치 (`INPUT_PULLUP`) |
| `7` | 부저 |
| `8` `9` `10` | 신호등 초록 · 노랑 · 빨강 |
| `9` | PWM 실습 (LED 밝기) |
| `13` | LED (보드 내장 LED와 공용) |
| `A0` `A1` `A2` | 자기장 센서 X · Y · Z |

## 파일 구성

빌드 도구 없이 동작하는 순수 정적 사이트입니다.

```
index.html            강의 목록 · 입력→연산→출력 · 준비물 · 안전 수칙
01-arduino.html       아두이노란?
02-ide.html           IDE 설치와 첫 업로드
03-led.html           LED 제어
04-buzzer.html        버저 출력
05-button.html        버튼 입력
06-traffic.html       신호등 만들기
07-project.html       프로젝트와 연계하기 (자기장 센서)
08-colab.html         코랩으로 선형회귀
assets/style.css      스타일

```

### 들어 있는 인터랙티브 요소

| 강의 | 시뮬레이터 |
|------|-----------|
| 03 | LED 깜빡임 — `delay()` 값을 슬라이더로 바꿔 확인 |
| 04 | 부저 건반 — Web Audio로 실제 소리 재생 + 멜로디 연주 |
| 05 | 버튼 입력 — 풀다운 / `INPUT_PULLUP` 값이 반대로 읽히는 것을 비교 |
| 06 | 신호등 자동 순환 · 보행자 버튼 신호등(부저 포함) |
| 07 | 시리얼 플로터 — 자석 근접에 따른 X·Y·Z 파형 |
| 08 | 최소제곱 — 슬라이더로 직선을 맞추며 SSE가 줄어드는 것을 확인 |

- 회로도와 보드 그림은 모두 인라인 SVG라 확대해도 깨지지 않고, 다크 모드에서 라벨 색이 함께 바뀝니다.
- 진도 체크와 체크리스트 상태는 브라우저의 `localStorage`에 저장됩니다.
- 인쇄용 스타일이 있어 그대로 유인물로 출력할 수 있습니다.

## 준비물 (학생 1인 기준)

아두이노 우노 R3 · USB A-B 케이블 · 브레드보드 · 점퍼선 10개 이상 ·
LED 빨강/노랑/초록 · 저항 220Ω 3개 · 저항 10kΩ 1개 · 수동 부저 1개 · 택트 스위치 1개

07강 추가: 3축 자기장 센서 모듈(아날로그 또는 I2C) · 네오디뮴 자석

08강은 부품이 필요 없습니다. 구글 계정과 인터넷만 있으면 됩니다.
