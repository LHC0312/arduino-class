## 구성 원칙 — 입력 → 연산 → 출력

아두이노가 하는 일은 늘 같습니다. 바깥 상태를 **읽고(입력)**, **판단하고(연산)**, 무언가를 **움직입니다(출력)**.
커리큘럼은 이 세 칸을 하나씩 채워 나가는 순서로 짜여 있습니다.

| # | 강의 | 구분 | 내용 |
|---|------|------|------|
| 01 | 아두이노란? | 개념 | 보드 구조, 핀 역할, 디지털/아날로그, `setup()` · `loop()` |
| 02 | IDE 설치와 첫 업로드 | 환경 | Arduino IDE 2.x 설치, 보드·포트 설정, Blink, 시리얼 모니터 |
| 03 | LED 제어 | **출력** | 브레드보드, LED 극성, 저항 계산, `digitalWrite` · `analogWrite` |
| 04 | 버저 출력 | **출력** | 능동/수동 부저, `tone()`, 주파수와 음높이, 배열로 멜로디 |
| 05 | 버튼 입력 | **입력** | 택트 스위치, 플로팅, 풀다운 · `INPUT_PULLUP`, 토글과 디바운스 |
| 06 | 신호등 만들기 | 종합 | 함수·배열·`millis()`, **상태 기계**로 만드는 보행자 신호등 |
| 07 | 프로젝트와 연계하기 | **입력** | 자기장 센서 `analogRead` X·Y·Z, 시리얼 플로터, 보정·필터·임계값 |
| 08 | 코랩으로 선형회귀 | **연산** | 구글 코랩, 최소제곱법, `np.polyfit`·scikit-learn, R², 센서 보정식을 아두이노로 |
| 09 | 3차원 자기장 시각화 | **연산** | pandas CSV, `quiver` 3D 벡터, `pivot` 히트맵, **분류 vs 회귀**, LOOCV |
| 10 | 측정부터 분석까지 | **측정+연산** | MagProbe로 CSV 추출, 파일명 규칙, 학습·테스트 구분, 거리 지수 회귀 |

06강 마지막에서 **버튼(입력) → 상태 전이(연산) → LED 3개 + 부저(출력)** 가 하나로 합쳐지고,
07강에서 버튼 자리에 센서를 끼워 넣어 실제 프로젝트로 확장합니다.
08강은 그 센서가 내놓는 숫자가 **실제로 몇 도인지**를 데이터로 찾아내, 구한 식을 다시 아두이노에 돌려놓습니다.
09강은 여러 지점에서 잰 값을 묶어 **자기장의 3차원 모양**을 그리고, 그 패턴으로 거꾸로 자석을 찾아냅니다.

08강이 회귀만 다루므로, 09강에서 **분류와 회귀를 나란히 놓고 언제 무엇을 쓰는지** 정리합니다.
자석 위치(P1~P9)처럼 후보가 정해진 문제는 분류, 자석까지의 거리처럼 연속적인 양은 회귀입니다.
거리는 세제곱 반비례라 곡선이지만, 로그를 씌우면 직선이 되어 8강의 선형회귀가 그대로 적용됩니다.

## 핀 배치 (전 강의 공통)

| 핀 | 용도 |
|----|------|
| `2` | 택트 스위치 (`INPUT_PULLUP`) |
| `7` | 부저 |
| `8` `9` `10` | 신호등 초록 · 노랑 · 빨강 |
| `9` | PWM 실습 (LED 밝기) |
| `13` | LED (보드 내장 LED와 공용) |
| `A0` `A1` `A2` | 자기장 센서 X · Y · Z |

## 09강 데이터 출처

09강의 측정값은 아두이노 우노 + QMC5883L(GY-271)로 실제 측정한 탐구 자료입니다.
4cm 간격 3×3 격자(M1~M9)에서 자석까지의 거리를 10·8·6·4cm로 바꿔가며 각 지점의 x·y·z를 기록한 것으로,
지점당 3개 × 9지점 = 27개 값이 한 세트입니다. 예제용으로 만든 값이 아니라서 이론과 어긋나는 부분이

### 수업에서 나오는 수치

8cm 실측 45점(셀별 중앙값)으로 `|B| = k/r^n` 을 맞추면:

| n | 로그 잔차 |
|---|---|
| 1 | 0.3409 |
| 2 | 0.2016 |
| **3** | **0.1379** |
| 4 | 0.2265 |
| 5 | 0.3709 |

연속으로 풀면 n = 2.90 (R² = 0.92). 쌍극자 이론값 3.00과 0.10 차이.

### 거리를 잘못 재면

`DEPTH` 를 바꿔가며 지수를 구하면:

| DEPTH | n |
|---|---|
| 70 mm | 2.47 |
| 75 mm | 2.68 |
| **80 mm** | **2.90** |
| 85 mm | 3.13 |
| 90 mm | 3.37 |
| 100 mm | 3.89 |

10mm 오차가 지수 0.2 이상을 바꿉니다. 수업에서 "분석보다 측정이 중요하다"는 지점으로 씁니다.
