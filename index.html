수업 준비물

아래는 학생 1인(또는 1조) 기준입니다. 대부분 아두이노 스타터 키트에 모두 들어 있습니다.

  • 아두이노 우노 R31개 · 호환보드 가능
  • USB 케이블1개 · A to B
  • 브레드보드1개 · 400핀 이상
  • 점퍼선10개 이상 · 수-수
  • LED빨강·노랑·초록 각 1개
  • 저항 220Ω3개 이상
  • 저항 10kΩ1개 · 5강
  • 부저1개 · 수동(패시브) 권장
  • 택트 스위치1개 이상 · 4핀
  • 노트북1대 · USB-A 포트 권장

7강(프로젝트)에서는 여기에 3축 자기장 센서 모듈과 실험용 네오디뮴 자석이 추가로 필요합니다. 센서 없이도 강의 내용은 그대로 읽고 이해할 수 있습니다.

USB-C만 있는 노트북이라면

USB-C ↔ USB-A 젠더나 USB 허브가 필요합니다. 수업 전에 미리 준비해 두세요. 충전 전용 케이블은 데이터 전송이 안 되므로 업로드가 실패합니다.

수업 진행 방식

  1. 읽고 이해하기

    각 강의의 개념 부분을 먼저 읽습니다. 회로 그림은 클릭해서 크게 볼 수 있습니다.

  2. 회로 만들기

    배선표를 보면서 브레드보드에 직접 꽂습니다. 배선 중에는 USB를 뽑아두세요.

  3. 코드 올리기

    코드 블록 오른쪽 위 복사 버튼으로 그대로 옮겨 붙여도 되고, 직접 타이핑해도 좋습니다. 타이핑을 권합니다.

  4. 바꿔보기

    각 강의 끝의 도전과제를 풀어봅니다. 숫자 하나만 바꿔도 동작이 달라지는 걸 확인하는 게 핵심입니다.

진도 저장

강의를 다 읽고 학습 완료로 표시를 누르면 왼쪽 목차에 체크가 남습니다. 체크리스트 상태도 함께 저장됩니다. 저장 위치는 이 브라우저이므로, 다른 컴퓨터에서는 다시 시작됩니다.

안전 수칙

아두이노는 5V로 동작해 감전 위험은 사실상 없지만, 보드가 망가지는 것은 순식간입니다. 아래 네 가지만 지키면 대부분의 사고를 막을 수 있습니다.

하지 말 것이유
USB가 꽂힌 채로 배선 바꾸기 실수로 5V와 GND가 닿으면 합선됩니다. 배선은 항상 전원을 뺀 상태에서.
LED를 저항 없이 연결 과전류로 LED가 타거나 핀이 손상됩니다. 반드시 220Ω을 직렬로.
5V와 GND를 직접 연결 완전 합선. 보드의 보호 회로가 동작하며 최악의 경우 USB 포트까지 나갑니다.
모터·전구를 핀에 바로 연결 디지털 핀 1개의 한계는 20mA입니다. 큰 부하는 별도 전원과 드라이버가 필요합니다.
타는 냄새가 나거나 보드가 뜨거우면

바로 USB를 뽑고 선생님을 부르세요. 다시 꽂아보는 것으로 확인하려 하지 마세요.
