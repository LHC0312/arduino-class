03강 · 실습

LED 제어

보드에 붙어 있는 LED 말고, 내가 직접 꽂은 LED를 켤 차례입니다. 여기서 배우는 “저항 + LED + GND” 한 세트가 앞으로 만드는 모든 회로의 기본이 됩니다.

이 강의를 마치면

  • LED의 극성을 구분하고 올바른 방향으로 꽂을 수 있다
  • 브레드보드의 어느 구멍끼리 연결되어 있는지 안다
  • 필요한 저항 값을 옴의 법칙으로 계산할 수 있다
  • digitalWrite와 analogWrite의 차이를 설명할 수 있다

준비물

  • 아두이노 우노USB 케이블 포함
  • 브레드보드1개
  • LED빨강 1개 (+ 예비)
  • 저항 220Ω1개 · 빨빨갈금
  • 점퍼선수-수 2개

LED 알아보기

LED는 정해진 방향으로만 전기가 흐르는 부품입니다. 거꾸로 꽂으면 고장 나지는 않지만 아무 일도 일어나지 않습니다. 수업 중 “안 켜져요”의 가장 흔한 원인입니다.

외우는 법

긴 다리 = 플러스. “길다”와 “+”가 모두 획이 길다고 생각하면 헷갈리지 않습니다.

저항은 왜 필요한가

LED는 전류를 스스로 제한하지 못합니다. 5V를 그대로 걸면 감당할 수 없는 양의 전류가 흘러 LED가 순식간에 타거나, 아두이노 핀이 손상됩니다. 그래서 전류의 양을 정해 주는 저항이 필요합니다.

옴의 법칙으로 계산하기

계산
R = (공급 전압 − LED 전압) ÷ 원하는 전류

  = (5V − 2V) ÷ 0.02A     ← 빨간 LED, 20mA = 0.02A
  = 3V ÷ 0.02A
  = 150Ω

→ 시중에 150Ω도 있지만, 여유를 두고 220Ω을 씁니다.
   220Ω일 때 실제 전류 = 3V ÷ 220Ω ≈ 0.0136A = 13.6mA
   조금 어둡지만 충분히 밝고, 훨씬 안전합니다.

빨강1.8 ~ 2.2V220Ω
노랑2.0 ~ 2.2V220Ω

빨강 · 빨강 · 갈색 · 금색 순서로 띠가 그려져 있습니다. 빨강(2) 빨강(2) 갈색(×10) → 22 × 10 = 220Ω, 금색은 오차 ±5%입니다. 색띠가 몰려 있는 쪽이 왼쪽입니다. 저항은 방향이 없어서 어느 쪽으로 꽂아도 됩니다.

브레드보드 원리

브레드보드는 납땜 없이 부품을 꽂아 연결하는 판입니다. 겉으로는 구멍만 잔뜩 뚫려 있지만, 안쪽에는 금속 클립이 정해진 규칙대로 들어 있습니다. 이 규칙을 모르면 회로가 절대 동작하지 않습니다.

같은 구멍 줄에 두 다리를 꽂으면

LED의 두 다리를 같은 세로줄에 꽂으면 그건 합선입니다. 전기가 LED를 거치지 않고 바로 지나가 버려서 불이 안 들어옵니다. 부품의 두 다리는 반드시 서로 다른 줄에 꽂아야 합니다.

회로 만들기

시작 전

USB 케이블을 뽑으세요. 배선이 다 끝난 뒤에 다시 꽂습니다.

배선표

순서연결부품
1아두이노 13 → 브레드보드 A열점퍼선 (빨강)
2브레드보드 A열 → B열저항 220Ω
3브레드보드 B열 → C열LED (긴 다리를 B열에)
4브레드보드 C열 → 아두이노 GND점퍼선 (검정)
저항의 위치는 앞이든 뒤든 상관없습니다

“13번 → 저항 → LED → GND”든 “13번 → LED → 저항 → GND”든 흐르는 전류는 같습니다. 직렬 회로이기 때문입니다. 중요한 건 저항이 회로 안에 있다는 것과 LED의 방향뿐입니다.

코드 작성

파일 → 새 스케치로 빈 창을 열고 아래 코드를 입력한 뒤 업로드합니다.

LedBlink.ino
// 13번 핀에 연결한 LED를 1초 간격으로 깜빡입니다.

const int LED_PIN = 13;   // 핀 번호에 이름을 붙여 두면 나중에 고치기 쉽습니다

void setup() {
  pinMode(LED_PIN, OUTPUT);   // 13번 핀을 '내보내는' 핀으로 설정
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  // 5V 출력 → LED 켜짐
  delay(1000);                  // 1초 유지
  digitalWrite(LED_PIN, LOW);   // 0V 출력 → LED 꺼짐
  delay(1000);                  // 1초 유지
}
명령뜻
const int LED_PIN = 13;13이라는 숫자에 LED_PIN이라는 이름을 붙입니다. 나중에 핀을 8번으로 옮기면 이 한 줄만 고치면 됩니다.
pinMode(핀, OUTPUT)그 핀을 출력으로 쓰겠다고 선언합니다. 빼먹으면 LED가 아주 희미하게 켜지거나 안 켜집니다.
digitalWrite(핀, HIGH)그 핀에 5V를 내보냅니다.
digitalWrite(핀, LOW)그 핀을 0V로 만듭니다.
delay(밀리초)그 시간 동안 아무것도 하지 않고 멈춰 있습니다.

값 바꿔보기

delay()의 숫자를 바꾸면 깜빡임이 어떻게 달라질까요? 아래 슬라이더를 움직여 미리 확인한 다음, 같은 값을 코드에 넣어 업로드해 보세요.

직접 확인해 볼 것

delay를 20 이하로 줄이면 어떻게 보이나요? 너무 빨라서 계속 켜져 있는 것처럼 보입니다. 사람 눈이 초당 약 50회 이상의 깜빡임을 구분하지 못하기 때문인데, 뒤에 나올 PWM이 바로 이 성질을 이용합니다.

LED 두 개 번갈아

LED를 하나 더 추가해 봅시다. 12번 핀에 저항 → LED → GND를 똑같이 하나 더 만들면 됩니다.

TwoLeds.ino
const int LED_A = 13;
const int LED_B = 12;

void setup() {
  pinMode(LED_A, OUTPUT);
  pinMode(LED_B, OUTPUT);
}

void loop() {
  digitalWrite(LED_A, HIGH);
  digitalWrite(LED_B, LOW);
  delay(400);

  digitalWrite(LED_A, LOW);
  digitalWrite(LED_B, HIGH);
  delay(400);
}

두 LED가 서로 반대로 켜집니다. delay()가 두 명령이 모두 실행된 다음에 오는 것이 중요합니다. digitalWrite 사이사이에 delay를 넣으면 두 개가 동시에 켜지는 순간이 생깁니다.

밝기 조절 · PWM

디지털 핀은 켬/끔만 가능한데, 어떻게 밝기를 조절할까요? 아주 빠르게 켜고 끄기를 반복하면 됩니다. 1초에 약 490번 깜빡이면서 “켜져 있는 시간의 비율”을 바꾸면, 우리 눈에는 밝기가 변하는 것처럼 보입니다. 이것을 PWM(펄스 폭 변조)이라고 합니다.

PWM은 아무 핀에서나 되지 않습니다

우노에서는 3, 5, 6, 9, 10, 11 번 핀만 가능합니다. 보드에 ~ 표시가 있습니다. 13번 핀은 PWM이 안 됩니다. 아래 실습을 하려면 LED를 9번 핀으로 옮기세요.

Fade.ino
// LED를 9번 핀(~ 표시)으로 옮긴 뒤 업로드하세요.

const int LED_PIN = 9;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // 어두운 곳에서 밝은 곳으로 (0 → 255)
  for (int level = 0; level <= 255; level++) {
    analogWrite(LED_PIN, level);
    delay(6);
  }

  // 다시 어둡게 (255 → 0)
  for (int level = 255; level >= 0; level--) {
    analogWrite(LED_PIN, level);
    delay(6);
  }
}
함수값의 범위결과
digitalWrite()HIGH / LOW완전히 켬 또는 완전히 끔
analogWrite()0 ~ 2550은 꺼짐, 128은 절반 밝기, 255는 최대 밝기

for (int level = 0; level <= 255; level++) 는 “level을 0부터 255까지 1씩 늘리면서 안쪽을 반복하라”는 뜻입니다. 같은 코드를 256번 쓰지 않아도 되게 해 줍니다.

② LED 3개로 흐르는 불빛

11, 12, 13번 핀에 LED를 하나씩 달고, 왼쪽에서 오른쪽으로 순서대로 켜지게 만들어 보세요.

힌트 보기

한 번에 하나만 켜지게 하려면, 새 LED를 켜기 전에 앞의 LED를 반드시 LOW로 만들어야 합니다. 이 패턴은 4강에서 배열로 훨씬 짧게 쓰는 법을 배웁니다.

③ 촛불 흉내내기

PWM과 random()을 써서, 밝기가 불규칙하게 흔들리는 촛불을 만들어 보세요.

힌트 보기

analogWrite(9, random(100, 255)); 뒤에 delay(random(40, 120)); 를 넣으면 됩니다. random(a, b)는 a 이상 b 미만의 숫자를 무작위로 돌려줍니다.

안 될 때

증상확인할 것
불이 전혀 안 들어옴① LED 방향 — 긴 다리가 저항(핀) 쪽인가? ② GND 선이 제대로 꽂혔는가 ③ 부품 두 다리가 같은 세로줄에 꽂혀 있지 않은가 ④ 코드의 핀 번호와 실제 꽂은 핀이 같은가
아주 희미하게 켜짐pinMode(핀, OUTPUT)을 빼먹었을 가능성이 큽니다. setup()을 확인하세요.
계속 켜져만 있음업로드가 실제로 되었는지 확인하세요. 코드를 고친 뒤 업로드를 다시 눌러야 반영됩니다. 또는 delay가 너무 짧습니다.
보드의 L LED만 깜빡임13번 핀은 내장 LED와 붙어 있습니다. 내 LED가 안 켜지면 배선 문제입니다.
LED에서 연기가 남저항 없이 연결했을 가능성이 큽니다. 즉시 USB를 뽑고 LED를 교체하세요.
