01강 · 개념

아두이노란?

아두이노를 “작은 컴퓨터”라고만 설명하면 감이 잘 안 옵니다. 무엇을 할 수 있고, 보드 위의 저 구멍들이 왜 저기에 있는지부터 봅시다.

이 강의를 마치면

  • 아두이노가 무엇이고 어디에 쓰이는지 설명할 수 있다
  • 우노 보드에서 디지털 핀·아날로그 핀·전원 핀을 찾을 수 있다
  • 디지털과 아날로그, HIGH와 LOW의 차이를 안다
  • setup()과 loop()가 각각 언제 실행되는지 안다

아두이노란 무엇인가

아두이노는 센서로 무언가를 감지해서, 판단하고, 부품을 움직이게 하는 작은 장치입니다. 정확히는 두 가지를 함께 부르는 이름입니다.

구분내용
보드
하드웨어		 손바닥만 한 초록색 기판. 가운데 칩이 프로그램을 실행하고, 가장자리 구멍(핀)에 부품을 연결합니다. 우리 수업에서는 Arduino Uno R3를 씁니다.
IDE
소프트웨어		 컴퓨터에 설치하는 무료 프로그램. 여기에 코드를 쓰고 USB로 보드에 올립니다. 아두이노에서는 이 코드를 스케치(sketch)라고 부릅니다.

핵심은 “입력 → 처리 → 출력” 흐름입니다. 버튼이 눌렸는지, 방이 어두운지, 온도가 몇 도인지를 입력받아, 코드로 판단하고, LED·모터·스피커를 출력으로 움직입니다. 자동문, 엘리베이터 버튼, 스마트 화분 물주기 장치 모두 같은 구조입니다.

한 줄 정리

아두이노 = 내가 원하는 조건대로 전기를 켜고 끄는 일을 자동화해 주는 부품. 사람이 스위치를 누르는 대신, 코드가 누릅니다.

왜 아두이노로 시작할까

  • 실패해도 부담이 없습니다. 보드 가격이 저렴하고, 5V로 동작해서 감전 위험이 사실상 없습니다.
  • 결과가 눈에 보입니다. 코드 한 줄을 고치면 LED가 실제로 다르게 깜빡입니다. 화면 속 숫자가 아니라 손에 잡히는 결과입니다.
  • 오픈소스라 자료가 많습니다. 회로도와 설계가 공개되어 있어 호환 보드가 많고, 막혔을 때 검색하면 대부분 답이 나옵니다.
  • 다음 단계로 이어집니다. 여기서 배운 개념은 라즈베리파이, ESP32, 로봇 제어로 거의 그대로 넘어갑니다.

보드 살펴보기

USB 케이블을 꽂기 전에, 보드에서 다섯 군데만 눈으로 찾아봅시다.

가장 많이 헷갈리는 것

13번 핀에는 이미 LED가 하나 붙어 있습니다. 보드에 L이라고 쓰인 작은 LED입니다. 그래서 아무것도 연결하지 않고도 13번 핀만으로 깜빡임 실습이 가능합니다.

핀 종류와 역할

핀방향설명
0 ~ 13입출력디지털 핀. 켬(5V)과 끔(0V) 두 가지 상태만 다룹니다. LED, 버튼, 부저에 사용합니다.
3 5 6 9 10 11출력위 디지털 핀 중 ~ 표시가 있는 것들. PWM으로 밝기·속도를 0~255 단계로 조절할 수 있습니다.
A0 ~ A5입력아날로그 핀. 0~5V 사이의 값을 0~1023 숫자로 읽습니다. 조도·온도 센서, 가변저항에 사용합니다.
5V출력부품에 5V 전기를 공급합니다. 회로의 (+)입니다.
3.3V출력3.3V로 동작하는 부품용. 이번 수업에서는 쓰지 않습니다.
GND—접지, 회로의 (−). 세 개가 있지만 모두 안에서 연결되어 있어 아무거나 써도 됩니다.
0, 1USB 통신에도 함께 쓰입니다. 가급적 사용하지 마세요. 여기에 부품을 꽂으면 업로드가 실패할 수 있습니다.
전류 한계

디지털 핀 하나가 감당할 수 있는 전류는 최대 20mA(절대 한계 40mA), 보드 전체로는 200mA 정도입니다. LED는 약 15~20mA를 쓰므로 몇 개는 괜찮지만, 모터나 전구는 절대 핀에 직접 연결하면 안 됩니다.

꼭 알아야 할 용어

디지털 (Digital)
중간이 없는 신호. 켜짐 아니면 꺼짐, 둘 중 하나입니다. 형광등 스위치를 생각하면 됩니다.
아날로그 (Analog)
연속적으로 변하는 신호. 0%부터 100%까지 모든 값이 가능합니다. 조명 밝기 조절 다이얼을 생각하면 됩니다.
HIGH / LOW
디지털 핀의 두 상태를 부르는 이름입니다. HIGH = 5V(켬), LOW = 0V(끔). 코드에서는 digitalWrite(13, HIGH)처럼 씁니다.
입력 (INPUT) / 출력 (OUTPUT)
핀이 신호를 읽을지(입력), 신호를 내보낼지(출력)를 정하는 것. LED는 출력, 버튼은 입력입니다. pinMode()로 지정합니다.
스케치 (Sketch)
아두이노에서 부르는 프로그램의 이름. 확장자는 .ino입니다.
업로드 (Upload)
컴퓨터에서 작성한 스케치를 USB를 통해 보드의 칩에 옮겨 넣는 것. 한 번 업로드하면 USB를 빼도 전원만 있으면 계속 실행됩니다.
GND (그라운드)
회로의 기준점이자 (−)극. 전기는 5V에서 나와 부품을 거쳐 GND로 돌아옵니다. 이 길이 끊기면 아무것도 동작하지 않습니다.

스케치의 구조

모든 아두이노 스케치에는 함수 두 개가 반드시 있습니다. 이름도, 역할도 정해져 있습니다.

sketch.ino
void setup() {
  // 전원이 켜질 때 딱 한 번만 실행됩니다.
  // 준비 작업을 여기에 씁니다. (핀 설정 등)
  pinMode(13, OUTPUT);
}

void loop() {
  // setup() 이 끝나면, 전원이 꺼질 때까지 무한 반복됩니다.
  digitalWrite(13, HIGH);   // 13번 핀에 5V를 내보낸다 → LED 켜짐
  delay(1000);              // 1000밀리초(=1초) 동안 그대로 기다린다
  digitalWrite(13, LOW);    // 13번 핀을 0V로 → LED 꺼짐
  delay(1000);
}
함수실행 횟수여기에 쓰는 것
setup()딱 1번핀 모드 설정, 시리얼 통신 시작 등 준비 작업
loop()무한 반복실제로 반복해야 하는 동작 — 깜빡이기, 센서 읽기, 판단하기

위 코드에서 delay(1000)의 1000은 밀리초(ms)입니다. 1000ms = 1초. 즉 이 스케치는 1초 켜고 1초 끄기를 영원히 반복합니다. 이 숫자를 100으로 바꾸면 훨씬 빠르게 깜빡입니다.

문법에서 자주 틀리는 것
  • 모든 명령 끝에 세미콜론 ; 을 붙입니다. 이걸 빼먹는 게 오류 1위입니다.
  • 대소문자를 구분합니다. digitalWrite는 되지만 digitalwrite는 안 됩니다.
  • 여는 중괄호 { 와 닫는 중괄호 } 는 항상 짝이 맞아야 합니다.
  • // 뒤는 주석입니다. 사람이 읽는 메모이고, 보드는 무시합니다.

확인 문제

1. LED를 켜려면 핀을 어떤 상태로 만들어야 할까요?

답 보기

HIGH입니다. HIGH는 그 핀에 5V가 나온다는 뜻이고, 전기가 흘러 LED가 켜집니다. LOW는 0V라 전기가 흐르지 않습니다.

2. 버튼이 눌렸는지 확인하려면 그 핀은 입력일까요, 출력일까요?

답 보기

입력(INPUT)입니다. 아두이노가 신호를 읽어야 하기 때문입니다. 반대로 LED는 아두이노가 신호를 내보내야 하므로 출력입니다.

3. delay(500)은 몇 초를 기다릴까요?

답 보기

0.5초입니다. 단위가 밀리초라서 1000으로 나누면 초가 됩니다.

4. 온도 센서 값처럼 “23.5도”같이 연속적인 값을 읽으려면 어느 핀에 꽂아야 할까요?

답 보기

아날로그 입력 핀(A0~A5)입니다. 디지털 핀은 켜짐/꺼짐만 구분하므로 중간 값을 읽을 수 없습니다.
